# מחולל תרגילי קורות

מפיק תרגילים בסגנון שרטוט בחינה (שחור-לבן) כ־**PNG + JSON** בפורמט `extracted` שתואם למאגר הבוט.

## תצורה נעולה

- **איך התרגיל נראה** נקבע רק ב־`render/` — מנוע שרטוט אחד קבוע (קורה, סמכים, עומסים, מידות, תוויות).
- **אילו נתונים** נכנסים לשרטוט נקבעים מתבנית הנתונים הנעולה `LOCKED_FAMILY` (= `overhang_stepped_udl` כרגע).
- אות **B** בבוט ו־`python -m exercise_generator` בלי `--family` תמיד משתמשים בתצורה הזו.
- כשנגדיר חוקי בחירת נתונים — הם ישנו מספרים/מיקומים **בתוך** אותה תצורת שרטוט, בלי להחליף «מראה» בין תבניות שונות.

בשלב זה:
- **מרווחים בין נקודות** (מידות לאורך הקורה): כל מרווח ב־80% מספר שלם, ב־20% עשרוני עם ספרה אחת.
- **אורך קורה `L`:** סכום המרווחים, תמיד בין 4 ל־12 מ'.
- שאר הנתונים (עומסים וכו') עדיין ערכי דוגמה קבועים עד שיוגדרו חוקים נוספים.

## הרצה

מתוך שורש `BotFuther`:

```bash
python -m exercise_generator --count 20 --out output/batch1
python -m exercise_generator --list-families
```

כל תרגיל: `ex_0001.json` + `ex_0001.png` בתיקיית `--out`.

`--family` שמור לפיתוח בלבד (כפיית תבנית נתונים אחרת); לא בשימוש בזרימת הבוט.

## מבנה

- `render/` — **קוד נעול למראה**
- `templates/` — בניית נתונים (`LOCKED_FAMILY` פעילה)
- `schema.py` — מודל + `to_extracted()`
- `pipeline.py` — generate → validate → JSON/PNG
- `randomize.py` / `validate.py` — שלד הגרלה + ולידציה מבנית מינימלית
