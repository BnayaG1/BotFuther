# Project Rules

## Communication Style
- **Concise & Direct**: Be extremely concise and direct in chat responses. Avoid unnecessary fluff, long intros, or excessive explanations. Keep correspondence brief, precise, and focused.
- **Clean & Focused Text**: Always provide clean, focused, and minimal text without boilerplate or filler.
- **No Emojis**: Do not use any emojis in chat responses, code, UI, comments, or documentation.

## Execution
- **Strict Scope**: Do strictly what is requested. No unprompted extra changes, assumptions, or over-engineering.
- **No Unprompted Git Push**: Never run `git push` or modify git tracking/gitignore unless explicitly instructed by the user.
- **No Test Runs**: Never run tests (pytest or any test suites) unless explicitly requested by the user.


## Architecture & Code Structure
- **Clean Architecture**: Always prioritize clean organization, modularity, and proper structural architecture.
